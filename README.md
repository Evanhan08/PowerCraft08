# PowerCraft08 Website

PowerCraft08 is a personal gaming and projects website. It shows my YouTube channel videos, my showcase builds, and tutorial guides in one place. The channel makes creative builds in sandbox games like Roblox Plane Crazy, Minecraft, and Mechanica.

**Live website:** https://evanhan08.github.io/PowerCraft08/

## About the Project

- **Made by:** Stephen John Cortez
- **Section:** WD-202
- **Activity:** PowerCraft08 Website

The goal of the website is to make the channel's videos and projects easy to find. Visitors can also send a build idea through the contact form.

## Pages

| Page | What it shows |
| --- | --- |
| `index.html` | Home page with the hero, featured build video, and featured videos |
| `videos.html` | All videos, with buttons to filter by game |
| `projects.html` | Showcase builds and tutorial projects |
| `about.html` | The story of the channel and a breakdown of its content |
| `contact.html` | Build request form and contact links |
| `template.html` | Blank page with the same header, menu, and footer, used to make new pages |

## Features

- Responsive layout for mobile, tablet, and desktop
- Hamburger menu on small screens
- Video filter buttons on the Videos page
- Build request form with a check for empty fields
- Featured video with captions and audio descriptions
- Links to Discord, TikTok, Roblox, and YouTube

## Folders

- `css` - the stylesheets (`styles.css` and the minified `styles.min.css`)
- `js` - `script.js` for the menu, the filter buttons, and the form
- `img` - images, the logo, and the `icons` folder
- `media` - the featured video and its caption files
